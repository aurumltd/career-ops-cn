# 模式：培训课程 — 技能提升投资回报评估

## 当用户考虑报班、考证、报课程时使用此模式 — 帮他算清楚 ROI

## 评估框架

### 第一步：成本核算（不要只看价格，算真实成本）

| 成本类型 | 计算方式 |
|----------|---------|
| 💰 直接成本 | 学费、报名费、材料费 |
| ⏰ 时间成本 | 每周需要花多少小时？折算成时薪 |
| 📉 机会成本 | 花这个时间你本来可以做什么？（刷题/投简历/做项目） |
| 🧠 精力成本 | 上完班已经很累了，还有精力学习吗？ |

**真实成本 = 直接成本 + 时间成本 + 机会成本

### 第二步：收益评估（不要被营销话术迷惑）

| 收益类型 | 评估标准 | 权重 |
|----------|---------|------|
| 🎯 直接找工作 | 学完能拿到面试概率 +20%吗？ | 50% |
| 📈 长期能力 | 真实提升你未来 3 年有用吗？ | 25% |
| 🔗 人脉/背书 | 证书/社区有价值吗？ | 15% |
| 🧠 认知提升 | 对你的思维方式有提升吗？ | 10% |

### 第三步：ROI 计算

```
预期收益 = (薪资涨幅概率 × 预期薪资增长 + 其他收益

ROI = 预期收益 ÷ 真实成本

ROI > 2 → ✅ 值得投资
1 < ROI < 2 → ⚠️ 可以但没必要
ROI < 1 → ❌ 不要报
```

## 常见课程类型分析

### 🎓 硕士 / MBA
- **高价格课程
- 直接成本：10-50 万
- 时间成本：1-2 年全职 / 2-3 年在职
- **什么时候值得？
  - 转行必须要硕士：计算机/
  - 目标公司明确要求硕士学历
  - 顶尖名校 + 你已经有 5 年以上工作经验，需要管理岗门槛
- **什么时候不值得？
  - "不知道学什么，先读个研再说"
  - 普通学校非全日制，学费超过 20 万
  - 目标行业不看学历只看作品

### 🖥️ 技术训练营 / 编程培训班
- 直接成本：1-5 万
- 时间成本：3-6 个月
- **什么时候值得？**
  - 完全零基础转行，需要有人带你入门
  - 有真实项目实战 + 就业保障（写进合同那种）
  - 口碑真的有很多学员就业数据
- **什么时候不值得？**
  - "学完保证 2 万月薪"（这种保证都是假的）
  - 网上免费资源足够你自学，你只是懒
  - 教的都是 3 年前淘汰的技术

### 📜 证书（PMP / AWS / 各种认证
- 直接成本：3k-2 万
- 时间成本：1-3 个月
- **什么时候值得？**
  - 目标公司 JD 明确要求这个证书
  - 证书确实能帮你过简历关（某些国企/大厂
- **什么时候不值得？**
  - "有了这个证就能月薪 3 万"（想多了
  - 技术岗看代码不看证
