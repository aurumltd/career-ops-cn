# 模式：简历生成 — ATS 优化 PDF 生成

## 完整流水线

1. 读取 `cv.md` 作为事实来源
2. 如果 JD 不在上下文中，向用户索取（文本或 URL）
3. 从 JD 提取 15-20 个关键词
4. 检测 JD 语言 → 简历语言（默认中文）
5. 检测公司位置 → 纸张格式：
   - 美国/加拿大 → `letter`
   - 其他地区 → `a4`
6. 检测职位原型 → 调整表述框架
7. 重写专业摘要，注入 JD 关键词 + 职业转型桥梁
8. 选择与职位最相关的 3-4 个项目
9. 按 JD 相关性重新排序经验要点
10. 根据 JD 要求构建能力网格（6-8 个关键词短语）
11. 在现有成就中自然注入关键词（**绝不编造**）
12. 从模板 + 自定义内容生成完整 HTML
13. 将 HTML 写入 `/tmp/cv-candidate-{公司}.html`
14. 执行：`node generate-pdf.mjs /tmp/cv-candidate-{公司}.html output/cv-candidate-{公司}-{YYYY-MM-DD}.pdf --format={letter|a4}`
15. 报告：PDF 路径、页数、关键词覆盖率 %

## ATS 规则（确保解析干净）

- 单栏布局（无边栏，无平行列）
- 标准标题："专业摘要"、"工作经验"、"教育背景"、"技能"、"证书"、"项目经验"
- 图片/SVG 中无文本
- PDF 页眉/页脚无关键信息（ATS 会忽略）
- UTF-8，可选文本（非栅格化）
- 无嵌套表格
- JD 关键词分布：摘要（前 5 个）、每个角色的第一个要点、技能部分

## PDF 设计

- **字体**：Noto Sans SC（中文），标题 600-700，正文 400-500
- **字体自托管**：`fonts/` 目录
- **页眉**：姓名 24px 粗体 + 2px 渐变线条 `linear-gradient(to right, #0ea5e9, #8b5cf6)` + 联系方式行
- **章节标题**：13px，大写，字间距 0.05em，主色调
- **正文**：11px，行高 1.5
- **公司名称**：强调色 `#8b5cf6`
- **边距**：0.6in
- **背景**：纯白色

## 章节顺序（优化"6 秒招聘者扫描"）

1. 页眉（大字号姓名、渐变、联系方式、作品集链接）
2. 专业摘要（3-4 行，关键词密集）
3. 核心能力（6-8 个关键词短语，弹性网格）
4. 工作经验（倒序）
5. 项目经验（最相关的 3-4 个）
6. 教育与证书
7. 技能（语言 + 技术）

## 关键词注入策略（道德，基于事实）

合法重写示例：
- JD 说 "RAG 流水线"，CV 说 "带检索的 LLM 工作流" → 改为 "RAG 流水线设计与 LLM 编排工作流"
- JD 说 "MLOps"，CV 说 "可观测性、评估、错误处理" → 改为 "MLOps 与可观测性：评估、错误处理、成本监控"
- JD 说 "利益相关者管理"，CV 说 "团队协作" → 改为 "跨工程、运营、业务的利益相关者管理"

**永远不要添加候选人没有的技能。只用 JD 的准确词汇重写真实经验。**

## HTML 模板

使用 `templates/cv-template.html` 中的模板。将占位符 `{{...}}` 替换为自定义内容。
