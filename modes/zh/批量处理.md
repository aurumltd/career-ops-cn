# 模式：批量处理 — 并行职位评估

## 使用场景

当用户需要同时评估 **5+ 个职位** 时使用此模式。例如：
- 扫描后批量处理新职位
- 一次性导入多个 JD URL
- 招聘会后批量筛选

## 流水线

### 步骤 1：去重 + 预检

1. 收集所有输入的 URL/JD
2. 对照 `data/applications.md` 和 `data/scan-history.tsv` 去重
3. 过滤掉明显不匹配的职位（标题完全不相关、薪资差距过大等）
4. 输出：**将处理 X 个职位，跳过 Y 个重复/不匹配**

### 步骤 2：分批并行执行

每批 **3 个职位**，并行使用子代理：

```bash
claude -p "评估这个职位：{URL}。只输出：评分 (X.X/5) + 一句话总结 + 关键匹配 + 关键差距。不要生成完整报告。"
```

每个子代理的输出格式：
```
【{公司} — {职位}】
评分：X.X/5
匹配：3 个关键优势
差距：2 个主要不足
一句话总结：...
```

### 步骤 3：排序 + 筛选

将所有职位按评分降序排序。用户决定进入下一阶段的数量（默认前 30%）。

### 步骤 4：完整评估（仅高分职位）

对筛选出的高分职位执行完整的 `评估` 流程：
- 完整 A-F 报告
- 生成定制 PDF
- 注册到追踪器

## 质量控制

- **子代理输出验证**：每个输出必须包含明确的数字评分
- **交叉验证**：评分接近阈值（±0.2）的职位由主代理重新评估
- **一致性检查**：同一家公司的不同职位评分差异不应超过 1.0

## 进度报告

每完成一批输出：
```
进度：已完成 X/Y，当前平均评分 Z.Z
下一批：[公司A, 公司B, 公司C]
```
