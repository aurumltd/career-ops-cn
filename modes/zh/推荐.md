# 模式：智能机会推荐与求职顾问

根据用户背景、技能和求职目标，提供个性化的机会推荐和求职策略建议。

---

## 触发方式

```
/career-ops-cn recommend
/career-ops-cn 推荐
/career-ops-cn advise
/career-ops-cn 建议
```

或者直接说："帮我分析一下求职方向"、"推荐适合我的机会"、"给我一些求职建议"

---

## 推荐工作流

### 第 0 步：智能问诊（必须先做）

**首先读取已有材料（cv.md、profile.yml、_profile.md），然后根据缺失信息最多问 5 个问题。**

**问诊问题模板（根据已有信息动态选择，不重复询问已有答案）：**

| 问题 | 目的 | 如果已有信息就跳过 |
|------|------|------------------|
| 1. 你目前的工作年限和职级是？（比如：3年高级开发 / 应届生 / 5年产品经理） | 判断经验层级和推荐方向 | cv.md 已有工作经历 |
| 2. 你期望的下一份工作是什么方向？（比如：AI 产品经理 / 全栈开发 / 转行做数据 / 先赚钱就行） | 对齐推荐目标 | profile.yml 已有目标职位 |
| 3. 有什么特殊背景或需求吗？（比如：留学生 / 女性求职 / 35+ 职场 / 想转行吗 / 需要远程） | 触发专属推荐策略 | 用户主动说过 |
| 4. 你最看重下一份工作的什么？（比如：薪资 / 成长 / 稳定 / Work-Life Balance） | 调整推荐权重 | _profile.md 已有偏好 |
| 5. 目前求职遇到最大的困难是什么？（比如：简历没人看 / 面试挂 / 不知道方向） | 给出针对性建议 | 用户主动说过 |

**问诊规则：**
- 最多问 5 个，最少问 1 个（如果信息很全可以直接开始分析）
- 每个问题简洁，用用户容易回答的方式
- 根据用户回答动态调整下一个问题
- 所有回答都记录到用户画像中，用于后续分析

**示例问诊开场白：**
> 我先快速了解一下你的情况，几个小问题：
>
> 1. 你目前的工作年限和职级是？
> 2. 期望的下一份工作方向是？
> 3. 有什么特殊背景或需求吗？（比如留学生、想转行、需要远程）
>
> 回答完这几个问题，我给你做完整的分析和推荐。

---

### 第一步：用户画像构建（必须执行）

**首先读取以下文件构建完整画像：**

1. `cv.md` - 简历全文，提取：
   - 教育背景（学校、专业、学历、是否海外留学）
   - 工作经历（公司、职位、年限、行业）
   - 技术栈/技能清单
   - 项目经验
   - 证书/认证

2. `config/profile.yml` - 个人配置：
   - 目标职位
   - 目标行业
   - 目标地点
   - 薪资期望
   - 其他个人偏好

3. `modes/_profile.md` - 用户原型配置

**如果以上文件不存在或信息不完整，主动询问用户补充。**

---

### 第二步：技能挖掘与潜力识别（深度分析）

**不要只看简历表面，进行深度挖掘：**

#### A. 显性技能（简历明确写出）
- 编程语言、框架、工具
- 行业知识、业务能力
- 软技能（沟通、管理、团队协作）

#### B. 隐性技能（简历没写但可推断）
- 根据项目描述推断："做过用户增长" → 隐含数据分析、A/B测试、用户心理洞察
- 根据公司背景推断："在大厂工作过" → 隐含流程规范、跨团队协作能力
- 根据职位推断："产品经理" → 隐含需求分析、项目管理、 stakeholder 沟通

#### C. 可迁移技能（转行/跨领域适用）
```
示例：
  教师 → 内容创作、课程设计、用户教育、结构化表达
  运营 → 数据分析、用户洞察、项目管理、增长思维
  开发 → 逻辑思维、问题拆解、系统设计、技术调研
```

---

### 第三步：机会匹配与推荐

**根据用户画像，分维度推荐：**

#### 🎯 维度 1：背景匹配推荐

| 用户特征 | 推荐机会类型 | 理由 |
|----------|-------------|------|
| **留学生/海归** | 外企、跨国公司、国际化团队、有海外业务的大厂 | 语言优势、跨文化能力、外企更认可海外学历 |
| **应届生/0-2年** | 管培生、大厂校招补录、快速成长型创业公司、大厂外包转正式 | 学习能力强、成本相对低、可塑性高 |
| **3-5年经验** | 高级工程师/产品、中型公司核心岗、大厂P6/P7 | 经验足够独当一面、性价比最高 |
| **5年+资深** | 技术专家、架构师、团队负责人、创业公司技术合伙人 | 深度积累、行业资源、领导力 |
| **转行人士** | 关联领域岗位、低门槛切入点、看重潜力的创业公司 | 过往经验可迁移、新领域学习快 |
| **女性求职者** | 有性别平权认证的公司、母婴友好政策、远程/灵活工作制 | 减少职场歧视、工作生活平衡 |

#### 🔍 维度 2：技能匹配推荐

**构建技能-岗位映射矩阵：**

| 技能组合 | 推荐岗位方向 |
|----------|-------------|
| Python + 数据分析 + SQL | 数据分析师、商业分析、数据产品经理 |
| React + Node + 前端工程 | 高级前端、全栈开发、前端架构师 |
| 机器学习 + 深度学习 + 部署 | AI 算法工程师、ML 工程师、MLOps |
| 产品思维 + 技术背景 + AI | AI 产品经理、技术产品经理、解决方案 |
| 项目管理 + 跨团队协作 | 项目经理、项目总监、COO 助理 |
| 写作 + 运营 + 数据分析 | 内容运营、增长黑客、品牌营销 |

#### 💼 维度 3：隐藏机会推荐（简历没直接匹配但值得考虑）

**不要只推荐用户明确写的方向，挖掘潜在匹配：**

- 示例：用户写"Java后端"，可以推荐"解决方案架构师"（技术背景+客户沟通）
- 示例：用户写"前端开发"，可以推荐"开发者关系 DevRel"（技术+社区+内容）
- 示例：用户写"数据分析"，可以推荐"产品运营"（数据驱动决策）

---

### 第四步：求职策略建议

**分模块给出可执行建议：**

#### 📝 简历优化建议（至少 3 条具体建议）

```
示例：
  ✅ 强化 AI 项目描述：目前只写了"做过推荐系统"，建议补充：
     - 用户规模（"服务 100 万+ 用户"）
     - 业务指标提升（"点击率提升 15%"）
     - 技术栈细节（"基于 PyTorch，使用协同过滤+深度学习混合模型"）

  ✅ 添加技能摘要部分：在简历顶部用 3 行概括核心竞争力，让 HR 3 秒抓住重点

  ✅ 量化成果：把"负责后台开发"改为"主导重构订单系统，接口响应速度提升 40%"
```

#### 🎨 作品集/证明材料建议

| 用户类型 | 建议内容 |
|----------|---------|
| **开发/算法** | GitHub 项目整理、技术博客、LeetCode 记录、开源贡献 |
| **产品/设计** | 产品分析文章、原型作品集、案例研究 Case Study |
| **运营/市场** | 增长案例、数据复盘、内容创作作品集 |
| **留学生** | LinkedIn 英文简历优化、海外项目经历翻译整理 |

#### 🔍 搜索策略建议

- **关键词组合**：推荐 3-5 个精准搜索关键词组合
- **公司名单**：推荐 10-15 家应该关注的公司（分层：冲刺/目标/保底）
- **渠道建议**：哪些招聘平台、哪些公众号、哪些社群、哪些猎头应该联系
- **时间策略**：金三银四、金九银十、年底跳槽窗口期等节奏建议

#### 🗣️ 面试准备建议

- 技术栈复习清单（根据目标岗位）
- 高频面试题预测（3-5 个核心方向）
- 故事银行构建：哪些项目经历应该重点准备 STAR 故事
- 反向面试问题：面试时应该问公司哪些问题

## 特殊场景处理

### 场景 1：留学生专属建议

- 抗风险行业和公司分析
- 降薪跳槽 vs 留守观望决策框架
- 如何通过副业/外包过渡
